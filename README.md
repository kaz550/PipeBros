# 土管兄弟 PipeBros

足場を下から叩いて敵をひっくり返し、同じ段へ移動して蹴り飛ばす、固定画面の2Dアクションゲームです。C++ / DxLibで制作しています。

**更新日：2026-10-17**。タイトル画面、基本の敵、得点・残機、次ステージへの進行まで実装済みです。現在は1人プレイ・カメ型の敵1種類・マップ1枚を繰り返す構成です。

- リポジトリ：[kaz550/PipeBros](https://github.com/kaz550/PipeBros)
- 詳細仕様：[GDD v1.1](docs/GDD.md)
- 授業共有用：[GDD v1.1 Word版](docs/PipeBros_GDD_v1.1.docx)
- 開発ベース：[Game A Week for DxLib Week05 Endless Jump Runner](https://github.com/kaz550/gaweek-week05-EndlessJumpRunner)

## 遊び方

1. 敵がいる足場を下からジャンプで叩きます。
2. 近くで接地している敵がひっくり返ります。
3. 転倒中・復帰中の敵に触れると、蹴り飛ばして100点を獲得します。
4. ステージ内の敵をすべて倒すと、次のステージへ進みます。

通常の敵に触れると残機が1つ減ります。残機があれば中央へ復帰し、0になるとゲームオーバーです。転倒した敵は時間経過で戻るほか、もう一度下から叩いても通常状態に戻ります。

## 操作

| 場面 | 操作 | キー |
| --- | --- | --- |
| ゲーム | 左右移動 | ← / → |
| ゲーム | 走る | Shift + ← / → |
| ゲーム | ジャンプ | Space。押す長さで高さが変化 |
| ゲーム | ゲーム全体を再開始 | R |
| ゲーム | 足場の判定表示を切り替え | F3 |
| タイトル | 項目を選ぶ | ↑ / ↓。W / S、ゲームパッドの十字キーも対応 |
| タイトル | 決定 | Enter / Space、ゲームパッドの決定ボタン |
| 操作説明 | タイトルへ戻る | Enter / Space |
| リザルト | 新しいゲームでリトライ | Enter / Space |
| リザルト | タイトルへ戻る | T |
| 共通 | アプリを終了 | Esc |

タイトルのメニューは **START GAME / HOW TO PLAY / EXIT** です。操作説明を開いていてもEscはアプリ終了になります。F1・F2は開発用のFPS表示・品質設定です。プレイヤーの操作は現在キーボードの左右キー・Shift・Spaceを使用します。

## 現在のルール

| 項目 | 実装内容 |
| --- | --- |
| 画面 | 1280 × 720、左右端がつながる固定画面 |
| 開始時の残機 | 3 |
| 得点 | 敵1体につき100点 |
| 初回位置 | 下段左側。Player1ポイントを使用 |
| 接触ミス後の位置 | 下段中央。PlayerRespawnポイントを使用 |
| 復帰時の無敵 | 2秒。半透明で表示し、最後の0.6秒は点滅 |
| 敵の転倒 | 同じ足場の打撃位置から80px以内で接地している敵が対象 |
| 敵の自然復帰 | 転倒6秒、復帰動作0.35秒を経て歩行に戻る |
| 再度の突き上げ | 転倒中・復帰中の敵を通常状態に戻す |
| 敵同士の接近 | 向かい合う歩行中の敵は両方反転。転倒中の敵には歩行中の側だけが反転 |
| 土管での周回 | 下段の出口で消え、2秒後に同じ側の上段へ戻る |
| 周回による加速 | 個体ごとに1周で基本速度の25％加算。最大2倍 |
| 通常ステージ | 制限時間なし。TIME表示と時間切れによるミスは無効 |
| ステージクリア | 配置された全個体の撃破で成立。出現待ちの敵は未撃破として数える |
| ハイスコア | ゲームオーバー後のリザルトでhiscore.datに保存 |

敵の速度は85 → 106.25 → 127.5 → 148.75 → 170px/秒と変化します。速度差のある敵が同じ向きに進み、後ろの敵が追いついた場合は後ろの敵が反転します。転倒・復帰・プレイヤーのミスで敵の速度は戻りません。次ステージやステージ全体の再開始では初期速度に戻ります。

## 画面と進行

**タイトル → STAGE 01を1.5秒表示 → プレイ → STAGE CLEARを1.2秒表示 → STAGE 02…**

開始表示中は操作・敵・制限時間を止めます。クリア表示中は最後の敵が飛ぶ演出だけを継続します。クリア後はリザルトを挟まず、得点と残機を次へ引き継ぎます。

現在はSTAGE 02以降も同じ `stage01.tmx` を使って敵を再配置します。ステージ番号は進みますが、別マップ・敵の構成変更・最終ステージはまだありません。

ゲームオーバー時はリザルトへ進みます。リトライとRでの全体再開始は、得点0・残機3・STAGE 01から始まります。

### ボーナス用のタイマー機能

`GameScene::GetStageTimeLimit_()` に制限秒数を設定すると、カウントダウン・TIME表示・残り10秒の赤色警告を有効にできます。0を返すステージは制限なしです。現在はすべて0です。

ボーナスステージ本体は未実装です。汎用タイマーには以前の「時間切れで残機を減らし、得点を保って同じステージをやり直す」処理が残っています。ボーナス専用の終了処理、残機への影響、報酬は別途決めます。

## Tiledによるステージ制作

- 保存形式：TMX（XML）。タイルデータはTMX内のCSV、圧縮なし
- マップ：有限・直交。40列 × 23行、1タイル32px
- マップ範囲：1280 × 736px。画面の表示範囲は1280 × 720px
- タイルセット：外部TSX。画像参照はTSXからの相対パス
- 独立したCSVファイルへの書き出しは不要

| レイヤー | 種類 | 用途 |
| --- | --- | --- |
| Background | タイル | 背景 |
| Platforms | タイル | 床と足場の見た目 |
| Pipes | タイル | 旧土管レイヤー。現マップでは空 |
| PipesVisual | タイルオブジェクト | 土管を32 × 64pxで配置 |
| Collisions | オブジェクト | 床と足場の矩形判定 |
| Spawns | オブジェクト | 初回位置、復帰位置、敵の出現口・出口 |
| Objects | オブジェクト | POWなどの配置予約。POWの効果は未実装 |

`Collisions` のオブジェクトIDを足場IDとして使い、`bumpable` を真偽値で指定します。地面は `Ground`、通常の地面は `bumpable=false` です。打撃時は周辺のタイル描画を持ち上げ、判定矩形は固定します。

### Spawnsのポイント

| 名前またはタイプ | Xの意味 | Yの意味 |
| --- | --- | --- |
| Player1 | プレイヤー判定の左端 | 足元 |
| PlayerRespawn | プレイヤー判定の中心 | 足元 |
| EnemySpawn | 敵判定の中心 | 足元 |
| EnemyExit | 土管への進入判定の境界 | 足元 |

Player1は `(220, 620)`、PlayerRespawnは `(640, 620)`。PlayerRespawnのXは中心なので、幅40pxのプレイヤー左端は620pxになります。旧マップにPlayerRespawnがない場合も、Groundの中央へ復帰します。

EnemySpawnとEnemyExitの向きは `direction` プロパティの `1` が右、`-1` が左です。詳しい配置値と注意点はGDDを参照してください。

## 画像とファイル配置

| ファイル | 現在の仕様 |
| --- | --- |
| assets/images/pipe_bros.png | 1402 × 1122px。アイドル2・歩き3・走り3・ジャンプ5の計13コマ |
| asset/images/enemy_turtle.png | 1774 × 887px。通常3・転倒2・復帰1・撃破1の計7コマ |
| assets/images/stage_tiles.png | 1254 × 1254pxのタイル画像 |
| assets/images/title_bg.png | タイトル背景・ロゴ・キャラクターを含む画像。1280 × 720へ拡大縮小して表示 |
| assets/stages/stage01.tmx | 現在のマップ |
| assets/stages/stage_tiles.tsx | 外部タイルセット |

敵画像はユーザー指定の `asset/images` を優先し、`assets/images/enemy_turtle.png` も代替として読み込みます。`asset` と `assets` の違いに注意してください。

キャラクター画像は各コマの矩形と基準点を個別に指定します。歩き・走りの画像は3枚ですが、再生は **1 → 2 → 3 → 2** の4ステップです。ジャンプは上昇・頂点・下降・着地に合わせてコマを選びます。見た目の大きさと接触判定は別管理です。

## 開発環境と実行

Windows / C++ / DxLib / Visual Studioを使用します。C++17を有効にし、既存のソリューションを開いて、DxLibのインクルード・ライブラリ設定を確認してビルドしてください。

実行時の作業ディレクトリから `assets` と `asset` を参照できる配置にします。画像・TMX・TSXの参照先を移動した場合は、相対パスも合わせて修正してください。ハイスコアは作業ディレクトリの `hiscore.dat` に保存されます。

XML読み込みには `src/ThirdParty/tinyxml2` を使用します。描画、足場判定、敵管理、ゲーム進行の主な担当は次のとおりです。

| ファイル | 担当 |
| --- | --- |
| src/Game/Player.* | 入力、移動、ジャンプ、復帰、スプライト |
| src/Game/StageData.* | TMXの判定矩形・各ポイントの読み込み、移動衝突 |
| src/Game/StageRenderer.* | タイルと土管の描画、足場の局所的な持ち上げ |
| src/Game/EnemyManager.* | 敵の移動、接触、転倒、再出現、周回加速 |
| src/Scene/GameScene.* | 得点・残機、開始とクリア、次ステージ、任意タイマー |
| src/Scene/TitleScene.* | タイトルメニュー、操作説明、ハイスコア表示 |
| src/Scene/ResultScene.* | ゲームオーバー後の結果とリトライ |
| src/Core/App.cpp | アプリ全体、入力取得、共通表示、終了時の後片付け |

# 土管兄弟 コメント付きソース

添付src.zipを基準に、自作49ファイルへ日本語の説明コメントを追記した版です。srcフォルダーは全文を同梱しています。

- [不要コード候補と整理方針](docs/UnusedCodeReview.md)
- [コメント付きソースの読み方](docs/CommentGuide.md)
- [確認結果](docs/Validation.md)

## 適用

展開したsrcフォルダーをプロジェクトのsrcへ上書きしてください。ソリューションやプロジェクトへ新しい.cpp/.hを登録する必要はありません。

自作ソースはUTF-8 BOM付き・CRLFです。元からCP932だった日本語コメントもUTF-8へ変換しています。ゲームのロジック・定数・文字列・ヘッダー参照は変更せず、コードやファイルの削除もしていません。ThirdParty/tinyxml2のコードとライセンスは元のままです。

不要コード候補には旧ランナーの13ファイル、未参照の取得関数、使われない集計データ等を挙げています。削除する場合の依存関係と、タイマーなど保持すべき処理も区別しました。

Windows/Visual Studioでの実ビルドは未実施です。コメントを除いたトークン列が元ソースと一致することと、相対include・ZIPの整合性を確認しています。

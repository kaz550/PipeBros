# スクリーンショットの追加

このフォルダーのPNGは差し替え用の仮画像です。実際の画面を撮影して、同じファイル名で上書きしてください。推奨サイズは1280×720pxです。

| ファイル名 | 撮影する場面 |
| --- | --- |
| title.png | START GAMEを選択したタイトル |
| gameplay.png | PLAYER 1 スコア カメやカニ POWが見える通常プレイ |
| how-to-play.png | タイトルのHOW TO PLAYダイアログ |
| bonus.png | STAGE 04のコインとBONUS TIMEが見える画面 |
| result.png | GAME OVERのリザルトダイアログ |
| stage-select.png | F3 ON → F4で開くステージ選択 |

通常プレイの撮影ではF3をOFFにして判定枠を消します。ボーナスへはF3→F4→STAGE 04で移動でき、選択後にF3をOFFにして撮影できます。

画像を差し替えたら、ルートREADMEの「現在は差し替え用の仮画像です」という段落と、画像代替テキストの「仮画像」を更新してください。6枚すべてでなく一部だけ置き換えた場合は、残りの仮画像表示を維持してください。

画像をREADMEと一緒にGitへ追加・コミットすると、GitHub上の相対パスで表示されます。ファイル名を変更する場合はルートREADMEの画像パスも変更してください。

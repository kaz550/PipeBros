# スクリーンショットの追加

PNGを1280×720pxで撮影し、同名で保存するとルートREADMEに表示されます。仮画像は実際のゲーム画面ではありません。

| ファイル名 | 撮影する場面 |
| --- | --- |
| title.png | 1 PLAYER / 2 PLAYERSが見えるタイトル |
| gameplay.png | 1人の通常プレイ。スコア・敵・POW |
| gameplay-2p.png | 橙1Pと水色2P、左右の個別スコアが見える2人プレイ |
| how-to-play.png | 2人用の操作が見えるHOW TO PLAY |
| bonus.png | STAGE 04のコインとBONUS TIME |
| result.png | 2人分の得点が見えるGAME OVER |
| stage-select.png | F3 ON → F4で開くステージ選択 |

通常撮影ではF3をOFFにして判定枠を消します。ボーナスへはF3→F4→STAGE 04で移動し、選択後にF3をOFFにできます。画像を差し替えたら、READMEの該当する仮画像表記も更新してください。画像とREADMEを一緒にGitへ追加・コミットすると相対パスで表示できます。

この更新パッケージは新しいgameplay-2p.pngだけを同梱します。既存6枚はそのまま残してください。

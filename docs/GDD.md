# 土管兄弟 ゲームデザインドキュメント
バージョン 1.2　更新日 2026年10月23日

足場を下から叩いて敵をひっくり返し、復帰する前に同じ段へ移動して蹴り飛ばす、固定画面の2Dアクションゲーム。敵を無力化する場所と、倒しに行く経路を判断する遊びを中心とする。

本書は制作中の仕様を共有し、学生が企画と実装の対応を学ぶための資料である。POW、カメとカニ、4ステージ周期、コインを集めるボーナス、デバッグ用ステージ選択まで実装した現行版の仕様を示す。

## 1 作品概要
| 項目 | 現在の仕様 |
| --- | --- |
| 作品名 | 土管兄弟 PipeBros |
| ジャンル | 固定画面 2Dアクション |
| 対象環境 | Windows PC ／ C++17 ／ DxLib |
| 画面 | 1280 × 720px ／ 目標60FPS |
| 人数 | 1人プレイ。2人同時プレイは拡張予定 |
| 制作 | Visual Studio ／ Tiled ／ TMXと外部TSX |



基準はmainのコミット07b1e722d4d70470e81a933c39ed94b059c212ae。地形はstage01.tmxを共用し、ゲーム側で敵構成と通常・ボーナスを切り替える。未実装の拡張は第10章に分ける。


## 2 基本ルールとゲーム進行
### 遊びの流れ
敵のいる足場を確認し、下の段からジャンプで叩く。近くの敵が転倒したら、その段へ移動して接触し、撃破する。歩行中・怒り中の敵への接触はミスとなるため、転倒を起こす操作と撃破を確定する移動を分けて考える。

### ステージ開始とクリア
タイトルでSTART GAMEを選ぶと、中央にSTAGE 01を1.5秒表示する。その間はプレイヤー操作・敵・プレイ時間を止める。表示後にプレイを開始する。

配置された撃破対象をすべて倒すと、STAGE CLEARを1.2秒表示する。最後に倒した敵が飛ぶ演出は継続し、プレイヤー操作とプレイ時間は停止する。リザルトを挟まず、得点と残機を保って次の番号へ進む。

STAGE 01はカメ2体、02はカニ2体、03は各1体、04はボーナス。05以降も同じ4構成を繰り返す。最終ステージは未設定である。土管での再出現待ちは未撃破として数え、敵が見えない間も誤ってクリアしない。

### 得点と残機
| 項目 | 仕様 |
| --- | --- |
| 開始時の残機 | 3 |
| 敵の撃破 | カメ・カニとも1体100点。重複加点しない |
| ボーナスのコイン | 1枚100点。既定10枚を全回収すると追加1000点 |
| 通常の接触ミス | 残機を1つ減らす。敵とステージの進行は維持 |
| 次ステージ | 得点と残機を維持。今回の撃破数と周回加速を初期化 |
| ゲームオーバー | 残機0で成立。1.2秒の表示後にリザルトへ進む |
| リトライとR再開始 | 得点0、残機3、STAGE 01から新しいゲームを開始 |
| ハイスコア | ゲームオーバー後のリザルトでhiscore.datに保存 |

ステージをやり直す場合も、獲得した点数は引き継ぐ。再配置された敵を倒すと改めて得点を得る。実装では、前回までの得点と今回の撃破数による得点を合算する。

リザルトの得点とプレイ時間はゲーム全体の累計である。DEFEATEDは現在のステージの挑戦における撃破数で、過去ステージの累計とは区別する。


### ボーナスステージ
4、8、12…のステージは、敵もPOWもないコイン回収ステージ。開始表示が終わってから20秒を計る。通常の移動・走り・ジャンプで10枚を回収し、全回収ならPERFECT!、時間切れならBONUS FINISHを1.2秒表示して次へ進む。残り10秒以下は時間を赤く表示する。

1枚100点、全回収で追加1000点。既定配置の満点は2000点。時間切れでも残機・ミス回数は減らさず、取得分の得点を引き継ぐ。全回収の加点は1回だけ。通常ステージには時間制限を設けない。

コインはBonusCoinsレイヤーのポイントを中心に24pxで配置する。床に5枚、下段足場に4枚、中段中央に1枚。回転中も回収判定は一定とし、移動区間と画面端の折り返しも判定する。開始表示とステージ選択ダイアログ中は時間を止める。


## 3 プレイヤーとミス後の復帰
### 操作と移動
| 操作 | キー | 挙動 |
| --- | --- | --- |
| 左右移動 | ← ／ →、A ／ D、パッド左右 | 通常220px毎秒 |
| 走る | Shiftまたはパッド2と左右移動 | 360px毎秒 |
| ジャンプ | Spaceまたはパッド1 | 押した瞬間に開始。接地中のみ可能 |
| 高さの調整 | Spaceを長く押す | 上昇中の重力を軽減し、早く離すと上昇を弱める |
| 全体再開始 | R | 得点と残機を初期化し、開始表示へ戻る |
| 判定の表示 | F3 | 足場矩形とIDのデバッグ表示を切り替える |
| ステージ選択 | デバッグ表示中にF4 | 01から99のステージを選ぶ |

画面の左右端はつながる。足場への着地は落下中の上面通過、頭の衝突は上昇中の下面到達で判定する。端から離れたら落下する。ジャンプを押し続けても着地直後に自動で跳び直さない。

### 初回位置とリスポーン位置
初回とステージ開始時は下段左側のPlayer1から始める。接触ミス後は残機を減らし、プレイヤーを1秒非表示にする。待機後、POWが残っていればその時点の上面中央、使用済み・未配置ならPlayerRespawnへ戻す。画像やマップは読み直さない。速度・ジャンプ・向き・アニメーションを初期状態に戻す。敵の位置、転倒時間、周回速度は維持する。

| ポイント | 座標と意味 |
| --- | --- |
| Player1 | X=220は判定左端、Y=620は足元 |
| PlayerRespawn | X=640は判定中心、Y=620は足元 |
| 現在の判定サイズ | 幅40px、高さ80px |
| 中央復帰後の左端 | X=620。中心640から幅の半分を引く |

### 無敵の見せ方
復帰後は2秒間、通常の敵に触れても残機を減らさない。敵を蹴る操作は有効とする。通常は約50％の半透明で表示し、残り0.6秒は0.075秒ごとに半透明と非表示を切り替える。無敵が切れると通常表示へ戻る。

背景・足場・敵・HUDにはプレイヤーの透明度を適用しない。画面端に複製するプレイヤーにも同じ透明度を適用する。待機中はプレイヤーの操作・接触・蹴りを無効にし、敵は移動と復帰・周回を続ける。無敵2秒は待機後に姿を現した時点から開始する。待機中のジャンプ長押しは復帰後に再実行しない。専用の死亡アニメーションは未実装である。


## 4 カメとカニとPOW
### 敵の状態
| 状態 | 挙動 | 次の状態 |
| --- | --- | --- |
| 歩行 | 向きに従って移動。プレイヤーに接触するとミス | カメは打撃で転倒。カニは怒りまたは転倒。出口で再出現待ち |
| 転倒 | 横移動を止め、転倒姿勢で待つ | 6秒後に復帰動作。再打撃なら歩行 |
| 復帰動作 | 復帰姿勢で0.35秒待つ | 歩行。再打撃でも歩行 |
| 撃破 | 蹴られて飛び、足場を通り抜けて画面外へ消える | 非アクティブ。再出現しない |
| 再出現待ち | 描画と接触を止めて2秒待つ | 同じ側の上段で歩行 |

転倒中と復帰中は、プレイヤーが接触すると蹴り飛ばせる。撃破は1回だけ数え、100点を加点する。蹴り飛ばし中の敵が画面外へ出ても、上段へ再出現させない。

### 足場を下から叩く条件
叩いた足場のIDと打撃位置を記録する。その足場がbumpable=trueで、上面に接地している敵を調べる。足場との横方向の重なりがあり、敵の中心が打撃位置から80px以内の場合に反応させる。空中・別の足場・撃破中・再出現待ちの敵は対象外とする。

カメは歩行中なら1回で転倒し、転倒時間を6秒に設定する。転倒中または復帰中なら通常の歩行状態へ戻す。向きと周回数は維持し、小さく跳ねる動きを加える。再打撃で転倒時間を延長する仕様は採用しない。

### 表示と判定
カメの接触判定は幅48px、高さ36px。カニは幅56px、高さ36px。画像の透明部分を含む大きさとは別に管理する。転倒は姿勢と揺れ、復帰動作は別のコマで示す。復帰前の点滅演出はまだ追加していない。

プレイヤーと敵の接触は画面端の反対側の複製位置も調べる。通常状態へ戻った敵は、その時点から通常の接触ミスの対象になる。


### カニの打撃と怒り
カニは正面向きの赤い体、大きなハサミ、飛び出した目で表す。1回目の衝撃では転倒せず、怒った表情になって歩行速度を1.5倍にする。2回目の接地中の衝撃で転倒する。1回目で小さく跳ね、空中では次の衝撃を受けない。通常の床叩きとPOWの衝撃を通算する。

転倒・復帰中の再打撃、または自然復帰では通常状態へ戻り、次も2回の衝撃が必要になる。怒りと敵の種類は土管を通っても維持する。次ステージ・ステージ再初期化では通常状態へ戻る。

### POWの使用回数と消失
通常ステージの下段中央に、幅64px・高さ32pxのPOWを配置する。下から叩くと、距離や足場を問わず接地中の敵全体へ1回分の衝撃を与える。空中・撃破中・再出現待ち・非アクティブの敵は対象外。カメは転倒し、通常のカニは怒る。転倒・復帰中の敵は通常状態へ戻る。

| 残り使用回数 | 高さ | 上面のY | 状態 |
| --- | --- | --- | --- |
| 3 | 32px | 492 | 通常の大きさ |
| 2 | 24px | 500 | 少し薄くなる |
| 1 | 16px | 508 | さらに薄くなる |
| 0 | なし | なし | 表示と当たり判定を削除 |

下面Y=524を固定し、上面を下げて縮める。3回目の衝撃を敵へ適用した後で消す。上に乗る・横から触れるだけでは消費しない。プレイヤーだけのリスポーンでは使用状況を維持し、次の通常ステージやステージ再初期化で3回へ戻す。ボーナスでは配置しない。画面揺れと専用SEは未実装。


## 5 土管での周回と敵同士の反転
### 再出現と周回の数え方
初期状態では、左右の上段に各1体を置き、種類はステージ構成で決める。下段で、敵の進行方向と合う出口へ到達すると消え、2秒後に同じ側の上段へ戻る。同じ個体として扱い、総個体数や撃破数を増やさない。

上段へ戻った時点を1周とする。待機中は周回数を増やさず、上段への再出現時に個体ごとの速度を上げる。

| 完了した周回 | 速度倍率 | 移動速度 |
| --- | --- | --- |
| 0周 | 1.00倍 | 85px毎秒 |
| 1周 | 1.25倍 | 106.25px毎秒 |
| 2周 | 1.50倍 | 127.5px毎秒 |
| 3周 | 1.75倍 | 148.75px毎秒 |
| 4周以降 | 2.00倍 | 170px毎秒 |

1周ごとに初期速度の25％を加算し、周回分の上限を2倍とする。怒り中のカニはこの速度へ1.5倍を掛け、初期127.5px毎秒、周回上限で255px毎秒となる。上限に達すると加速用カウンタの加算も止める。LOOPS_PER_SPEEDUP、SPEED_GAIN_PER_LEVEL、MAX_SPEED_LEVELで調整する。歩行アニメーションも速度に比例して速くする。

### 接触直前の反転
| 組み合わせ | 反応 |
| --- | --- |
| 歩行同士が向かい合う | 両方が離れる向きへ反転 |
| 歩行と転倒中または復帰中 | 近づいている歩行中の側だけが反転 |
| 同方向で速い敵が追いつく | 後ろの速い敵が反転 |
| すでに離れている敵同士 | 再反転しない |
| 高さが重ならない敵 | 接触対象外 |

本体の間に8pxの余白を取り、次の移動で近づく場合も先に判定する。画面端をまたぐ距離にも対応する。転倒・復帰・反転で速度を初期化しない。ステージ全体の再開始と次ステージでは、個体を作り直して基本速度に戻す。


## 6 ステージとTiledのデータ
有限・直交のTMXにタイル配置とオブジェクトをまとめる。タイルデータはCSV・圧縮なしで保存し、独立したCSVには書き出さない。マップは40列×23行、1タイル32px。全体1280×736pxのうち1280×720pxを表示する。

| レイヤー名 | 種類 | 用途 |
| --- | --- | --- |
| Background | タイル | 背景 |
| Platforms | タイル | 床と足場の見た目 |
| Pipes | タイル | 現マップでは空の旧土管レイヤー |
| PipesVisual | タイルオブジェクト | 32×64pxの土管画像 |
| Collisions | オブジェクト | 床と足場の矩形判定 |
| Spawns | オブジェクト | 開始・復帰・敵出現・出口のポイント |
| Objects | オブジェクト | POWの矩形と位置 |
| BonusCoins | ポイントオブジェクト | ボーナスのコイン中心 |

座標は左上原点で、右が正のX、下が正のY。Collisions、Spawns、Objects内のPOW、BonusCoinsのレイヤーオフセットは0にする。Collisionsは回転のない矩形とし、オブジェクトIDを判定IDに使う。Groundは地面の名前で、叩けない設定とする。

| ポイント | 現在の値 | 座標の解釈 |
| --- | --- | --- |
| Player1 | 220, 620 | プレイヤー左端と足元 |
| PlayerRespawn | 640, 620 | プレイヤー中心と足元 |
| EnemyLeft | 96, 140 ／ 向き1 | EnemySpawn。中心と足元 |
| EnemyRight | 1184, 140 ／ 向き-1 | EnemySpawn。中心と足元 |
| EnemyExitLeft | 96, 620 ／ 向き-1 | EnemyExit。出口境界と足元 |
| EnemyExitRight | 1184, 620 ／ 向き1 | EnemyExit。出口境界と足元 |

EnemySpawnとEnemyExitはタイプまたはクラスで指定し、directionは1が右、-1が左。PlayerRespawnがない旧マップでは、Groundの中央と上面を使用する。EnemySpawnの文字列enemyTypeはturtleまたはcrab。省略時はturtle。GameSceneはステージ構成を優先し、EnemyManagerを既定のFromMapで初期化した場合だけenemyTypeを使う。

外部TSXは313×313pxの元タイルを16枚持ち、描画時にマップの32pxへ合わせる。土管はPipesVisualのタイルオブジェクトを幅32・高さ64に設定し、左下基準で配置する。足場を叩いた際は周辺の描画のみを持ち上げ、判定用の矩形は動かさない。


POWはObjectsレイヤー内のクラスまたはタイプがPOWの矩形を1個置く。現在はx=608、y=492、幅64、高さ32。可視の矩形を表示と判定で共通に読み込み、回転・画像オブジェクトには対応しない。

BonusCoinsには画面内のポイントを置く。中心は床の5枚がx=160、400、640、880、1120、y=580。下段の4枚がx=160、400、880、1120、y=420。中段の1枚が640、260。ポイントの追加・削除で回収目標枚数も変わる。


## 7 グラフィックとアニメーション
キャラクターとステージは画像素材で描く。メニューの枠や文字、HUD、当たり判定のデバッグ枠はコードで描画する。画像の寸法をそのまま当たり判定には使わない。

| 画像 | 寸法 | 内容 |
| --- | --- | --- |
| pipe_bros.png | 1402×1122px | プレイヤー13コマ |
| enemy_turtle.png | 1774×887px | カメ7コマ |
| enemy_crab.png | 1536×1024px | 通常歩行3 怒り歩行3 転倒2 撃破1 |
| pow.png | 1774×887px | 透過POW画像を64×32pxへ縮小 |
| bonus_coin.png | 1254×1254px | 回転4コマを約24pxへ縮小 |
| stage_tiles.png | 1254×1254px | 4列×4段のタイル画像 |
| title_bg.png | 生成画像を画面へ拡縮 | ロゴ・背景・兄弟のイラスト |

| プレイヤーの状態 | 画像の枚数 | 再生方法 |
| --- | --- | --- |
| アイドル | 2 | ループ |
| 歩き | 3 | 1→2→3→2の4ステップ |
| 走り | 3 | 1→2→3→2。歩きより短い間隔 |
| ジャンプ | 5 | 上昇開始・上昇・頂点・下降・着地で選択 |

各コマに切り出し矩形と基準点を持たせ、足元中央を描画位置に合わせる。各コマの大きさが違うため、画像を等間隔のセルへ機械的に分割しない。左右向きは画像の反転で扱う。

カメ型の敵は通常3枚を1→2→3→2で再生し、転倒2枚、復帰1枚、撃破1枚を使う。歩行だけ周回速度に合わせて再生を速め、転倒や復帰の時間は変えない。

### ファイルの配置
プレイヤー・タイル・タイトルの画像はassets/imagesへ置く。現リポジトリの画像はassets/imagesに揃っている。敵画像のローダーは互換性のためasset/imagesを優先し、なければassets/imagesを読む。同名の古い画像を両方に置かない。マップと外部タイルセットはassets/stagesへ置く。

専用のプレイヤー死亡コマ、2P用のプレイヤー、ハエ・炎・氷などの追加敵は今後の制作対象である。タイトルに兄弟2人を描いていても、現在のプレイ人数は1人である。


## 8 タイトルと画面のフィードバック
### タイトル
土管・レンガ・オレンジ色の作業服を共通の見た目とし、土管兄弟のロゴと背景を画像で表示する。START GAME、HOW TO PLAY、EXITの3項目とハイスコアをコードで描画する。

上下キーで項目を選び、EnterまたはSpaceで決定する。WとS、ゲームパッドのメニュー入力にも対応する。選択中の項目は金色で強調する。HOW TO PLAYは操作説明を重ねて表示し、EnterまたはSpaceで閉じる。Escは説明を閉じる操作ではなくアプリ終了である。

決定キーを押したまま画面へ入った場合は、離して再度押すまで決定しない。EXITは終了要求をAppへ渡し、音声とDxLibを後片付けして終了する。マウス操作は未実装である。

### ゲームとリザルト
左上にPLAYER 1、6桁スコア、残機、右上にステージ番号を表示する。操作説明・撃破数・無敵残時間は床より下へ置く。ボーナスでは上段中央にBONUS TIME、画面下に回収枚数を示す。Resultと同じArial太字を使用し、ラベル26、スコア32、補助18のサイズで描く。通常ステージにTIMEは表示しない。開始とクリアの短い表示はGameScene内で制御し、独立したシーンは作らない。

ゲームオーバー後のリザルトは得点、ハイスコア、残機、現在の挑戦の撃破数、累計プレイ時間を示す。ステージ背景を暗くした上に、HOW TO PLAYと同じ青緑のパネルと金枠を表示する。RETRYとTITLEを上下キーまたはW・Sで選び、Enter・Space・パッド1で決定する。Tまたはパッド2で直接タイトルへ戻る。Escはアプリ終了。表示開始0.25秒は入力を待つ。直前の決定キーの長押しで即リトライしないようにする。

### 音と演出
| 項目 | 現状 |
| --- | --- |

## 9 実装構成と確認項目
| 担当 | 主な責務 |
| --- | --- |
| Player | 左右移動、走り、可変ジャンプ、復帰、スプライト |
| StageData | TMXの矩形 各ポイント POW使用状況 コイン中心 移動衝突 |
| StageRenderer | タイルと土管の見た目、足場の局所演出 |
| EnemyManager | 敵の状態、反転、再出現、周回による加速 |
| GameScene | 得点 残機 復活待ち ステージ構成 ボーナス デバッグ選択 HUD |
| Input | キーとパッドの状態 押下 長押し 解放の共通管理 |
| TitleScene | タイトル画像、選択メニュー、操作説明 |
| ResultScene | ゲームオーバー後の集計、ハイスコア、リトライ |
| AppとSceneManager | 入力取得、フレーム更新、シーン切り替え、終了 |

1フレームでは、入力取得、プレイヤーの移動と足場衝突、敵の移動と打撃、プレイヤーとの接触、得点と進行判定、描画の順に処理する。敵同士の接触は移動前後に調べ、離れ始めた組み合わせを再反転させない。

### デバッグモードとステージ選択
F3で判定表示を有効にし、F4で選択ダイアログを開く。F3はGameSceneで1回処理し、開始表示・復活待ち中も使える。選択範囲は01から99。上下またはW・Sで1ずつ、左右またはA・Dで4ずつ移動し、端では折り返す。

Enter・Space・パッド1で開始、F4またはパッド2で取り消す。F3はデバッグをOFFにして閉じる。Escはアプリ終了である。ダイアログ中はプレイヤー・敵・タイマー・復活待ち・開始とクリアの待ち時間を止める。決定キーを押したまま開いた場合は、一度離してから再度押す。

選択開始時は得点・正の残機・累計時間を維持し、敵・コイン・POW・制限時間・無敵・復活待ち・クリア状態を初期化する。残機0から選択した場合は3へ戻す。Rでは通常どおりゲーム全体を再開始し、デバッグ表示をOFFにする。

### 受け入れ確認
- 通常ステージは時間制限なしで、カメ・カニ・混合・ボーナスの順に進む。
- カニは1回で怒り、着地後の2回目の衝撃で転倒する。
- POWは3回目も衝撃を伝えてから消え、次の通常ステージで復活する。
- ミス後は1秒待ってPOWの現在の上面か中央の床へ戻り、そこから無敵2秒になる。
- 待機中にプレイヤーが見えないまま敵を蹴ったり、再び残機を失ったりしない。
- ボーナスは20秒、1枚100点、全回収で追加1000点。時間切れで残機を減らさない。
- ステージ選択を開くと時間とゲームが止まり、取り消すと元の状態で再開する。
- ゲームオーバーだけリザルトへ進み、ハイスコアを保存し、リトライは新しいゲームになる。

### 教材として読む観点
Inputで入力の取得と参照を分け、描画と当たり判定、敵の個体状態とステージ全体の進行を分けて読む。POWは最後の衝撃を適用してから判定を削除する。復活待ちと無敵は別の時間として扱う。ボーナスの時間切れは通常の接触ミスと異なる分岐にする。
